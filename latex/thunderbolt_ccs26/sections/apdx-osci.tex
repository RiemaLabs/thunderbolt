\section{Open Science}\label{apdx:osci}

\paragraph{Artifacts and access}
The full artifact is hosted anonymously at \url{https://anonymous.4open.science/r/alma-ccs-1791/}. 
The repository contains source code, scripts, configuration, and documentation needed to evaluate the paper's core contributions.

\paragraph{Artifact contents}
\begin{itemize}
    \item Implementation of \tool, including schema analysis, bucket selection, concretization, the RL policy, and the fuzzing runtime.
    \item Benchmark definitions, bug patches, and oracles used for the evaluation (FSSZ/PSSZ suites and related harnesses).
    \item Scripts and configuration to reproduce TTE measurements and the results reported in \autoref{sec:eval}.
    \item Documentation describing setup, dependency versions, and required environment variables.
\end{itemize}


The evaluation uses open-source third-party dependencies that are fetched during setup.
The artifact pins the required versions and provides exact checkout instructions.

\paragraph{Responsible disclosure}
Because non-canonical SSZ inputs can be consensus-critical, we follow coordinated disclosure.
For vulnerability instances that were reported privately and are not yet publicly tracked, we will delay publishing exploit inputs until fixes are available.
For unresolved or unpatched issues, we will publish only sanitized metadata and non-exploitable test cases, and defer releasing full exploit-triggering payloads until a fix is publicly available.
