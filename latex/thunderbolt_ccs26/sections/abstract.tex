\begin{abstract}
    Inter-client consensus in proof-of-stake blockchains relies on a rigorous serialization layer to maintain a unified state history across diverse implementations. Implementation discrepancies in this layer, particularly regarding the handling of non-canonical but semantically equivalent encodings, can silently desynchronize honest nodes and partition the network. However, detecting such consensus-breaking behaviors is challenging because standard coverage-guided fuzzers lack the semantic awareness to navigate strict protocol constraints and often fail to probe the subtle boundaries between valid and invalid state representations.

    In this paper, we present \tool, a boundary-seeking fuzzing framework designed to expose logic bugs in inter-client state serialization. \tool introduces a specification-guided input abstraction (SGIA) which systematically derives a structured action space from protocol specifications and type constraints. This abstraction partitions the input domain into semantically meaningful buckets that represent edge cases, canonical forms, and boundary conditions. To effectively explore this space, \tool employs a reinforcement learning policy that ranks abstract buckets using a multi-armed bandit strategy. We propose a novel distributional reward mechanism based on the Kullback-Leibler divergence of batch-level execution signatures, which drives the fuzzer toward unexplored behavioral distributions and semantic edge cases that traditional metrics miss.

    We instantiated \tool for the Ethereum simple serialize (SSZ) protocol and evaluated it on a diverse set of production consensus clients. Our experiments establish a benchmark of 39 semantic boundary cases derived from historical SSZ vulnerabilities and regressions. In evaluation, \tool reproduced all 39 benchmarked SSZ issues and uncovered 12 previously unknown vulnerability instances across major clients and libraries, including one consensus-breaking divergence. These results demonstrate that steering fuzzing with specification-derived abstractions significantly improves the detection of deep semantic discrepancies in critical consensus infrastructure.
\end{abstract}
