Bitcoin Thunderbolt release verification

1. Push an exact vMAJOR.MINOR.PATCH tag to trigger the release workflow.
2. The workflow builds the tagged commit on each supported host and retains the
   platform archives, source archives, and per-binary SBOMs.
3. The publication job checks that the tag matches the Cargo workspace version,
   compares shared source artifacts, and creates one SHA256SUMS manifest over the
   complete GitHub Release asset set.
4. Publish the assets from the tag-triggered workflow. Never replace an artifact
   under an existing version; issue a new version instead.
5. Verify a download against SHA256SUMS and the exact tagged commit before use.

Maintainers may additionally create a detached GPG signature with:

   scripts/sign-release.sh RELEASE_DIRECTORY FULL_GPG_SECRET_KEY_FINGERPRINT

Verify that signature with:

   scripts/verify-release.sh RELEASE_DIRECTORY FULL_GPG_PUBLIC_KEY_FINGERPRINT
